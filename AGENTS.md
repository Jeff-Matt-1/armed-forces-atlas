# Working in this repository

The project was generated by Lovable and has since been disconnected from it:
the GitHub app no longer has access, and development happens here. Lovable's
bot used to commit to `main` on its own, so anything in the history authored
by `gpt-engineer-app[bot]` predates that.

`@lovable.dev/vite-tanstack-config` is still a dependency and must stay — the
whole build is configured through it, including nitro, TanStack Start, Tailwind
and the Cloudflare preset. It is build tooling, unrelated to the hosted service.

Deploys go to Cloudflare Workers via `bun run deploy`; see README.md.
